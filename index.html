Aktivitas terakhir

    Ilustrasi alur SDK — pseudocode

    Ini pseudocode ilustrasi alur, bukan kode siap deploy: nama method di bawah belum terverifikasi terhadap README / types paket @ammora-protocol/sdk v0.3.9. Gunakan hanya sebagai peta langkah, lalu samakan setiap signature dengan dokumentasi resmi paket sebelum menulis versi on-chain di proyek Next.js / Vite.

    npm i @ammora-protocol/sdk viem

// 1) Setup — GIWA Sepolia (chain 91342)
import { createConfig, Launchpad } from "@ammora-protocol/sdk";
import { createWalletClient, custom } from "viem";

const config = createConfig({ chainId: 91342 });
const launchpad = new Launchpad(config);

// 2) Buat token + bonding curve
const token = await launchpad.createToken({
  name: "Giwa Cat",
  symbol: "GCAT",
  totalSupply: 1_000_000_000n,
  curveSupply: 800_000_000n, // 80% dijual di kurva
});

// 3) Beli / jual di kurva
await token.curve.buy({ amountIn: "0.5" });  // ETH -> token
await token.curve.sell({ amountIn: "10000" }); // token -> ETH

// 4) Graduate otomatis ke pool AMM
// saat ETH terkumpul mencapai target kurva,
// sisa suplai + ETH dipindah ke pool AMM Ammora.

    Jangan deploy potongan ini apa adanya — verifikasi dulu setiap method & parameter di README paket @ammora-protocol/sdk, dan selalu testnet dulu.
