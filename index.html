Create a New Token

Choose a mode: Quick Create (one transaction: Config + token + curve) or Atomic Create + First Buy (the same, plus a WETH first buy in the same transaction). The preview is priced from the latest on-chain state before you sign anything.

Advanced settings
Fill in the form, then click “Create Token” for an on-chain preview. The preview computes the Config, price, and transaction value from the latest chain state.

Testnet gas is paid in GIWA Sepolia ETH from your wallet. A transaction is only created after you sign it in your wallet. Token & curve are read from the on-chain receipt, never predicted.
