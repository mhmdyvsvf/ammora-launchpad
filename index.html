Buat Token Baru

Pilih mode: Quick Create (satu transaksi: Config + token + kurva) atau Atomic Create + First Buy (sama, ditambah first buy WETH di transaksi yang sama). Preview dihitung dari state chain terbaru sebelum kamu menandatangani apa pun.

Pengaturan lanjutan
Isi formulir, lalu klik "Buat Token" untuk preview on-chain. Preview menghitung Config + harga + value transaksi dari chain terbaru.

Biaya gas testnet dibayar dari ETH GIWA Sepolia di wallet kamu. Transaksi dibuat hanya setelah kamu menandatangani di wallet. Token & curve dibaca dari receipt on-chain, bukan prediksi.
